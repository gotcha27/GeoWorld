# GeoWorld

Application web interactive permettant d'explorer les pays et territoires du monde.

## Technologies

- **Frontend :** Vue.js, Vite, MapTiler
- **Backend :** Node.js, Express, TypeScript
- **Base de données :** MySQL
- **ORM :** TypeORM
- **Environnement :** Docker Compose

## Organisation du projet

- `frontend/` : interface utilisateur et carte interactive
- `backend/` : API, logique métier et accès à la base de données

## Configuration

Les variables d'environnement nécessaires doivent être configurées localement. Ne publiez jamais de mots de passe, de jetons secrets ou de fichiers `.env`.

## Lancement

Le projet utilise Docker Compose. Consultez les fichiers de configuration du backend et du frontend pour préparer l'environnement local.
